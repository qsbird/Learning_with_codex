# Git 命令的源码之旅

一门独立、按需选学的临时支线课。从一个具体的 Git 命令行为出发，观察仓库数据，阅读对应 C 实现，再用小实验验证解释。

## 课程约定

- 不接入年度或其他跨主题计划，不占用已有课程的课时或里程碑。
- 不设截止日期、每周任务、复习安排、提醒或补课要求；想学时再选择一个单元。
- 每次只解决一个关键问题；需要的前置知识在当次讲解，不要求先通读全部源码。
- 记录本课实际发生的学习证据；教练准备资料、运行脚手架不代表学习者已经掌握。

## 文件与环境

- 可提交的课程资料和脚本保存在本目录。
- 临时实验仓库、下载的 Git 源码、Debug 构建和输出保存在仓库根目录的 `out/git-source/`。
- 首课使用 Windows PowerShell 或 PowerShell 7 和本机 Git，无需先编译 Git、安装依赖或联网。
- 源码阅读基线为上游 `v2.45.1`；本机观察到的程序是 `2.45.1.windows.1`。Windows 特有行为需另查对应版本；单步调试时使用与源码一致的自建程序。
- 后续换到 macOS/Linux 时，先按当次环境改写脚本调用与文件写入方式，再记录验证结果。

在仓库根目录准备首课实验：

```powershell
& ./topics/git-source/exercises/g1-add-snapshot/prepare.ps1
```

脚本只创建起始状态。已有同名实验目录时会退出，保留已有操作；可以通过 `-Name g1-add-snapshot-2` 创建另一份。
