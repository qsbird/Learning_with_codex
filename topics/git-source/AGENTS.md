# Git 源码临时支线课约定

- 学习者明确选择独立、按需选学：不接入年度计划或其他主题，不做跨主题进度对账，不评价提前、落后或逾期，不新增排期、复习、提醒或补课任务。这些选择优先于通用教练的计划对账与复习建议。
- `learning/roadmap.md` 是选学菜单。只在学习者要求学习时开始当次单元；当次理解检查和小变体可以保留，不生成后续复习安排。
- 沿“命令语义、数据变化、实际源码、实验结果”追踪；注明源码 tag。源码路径图要区分直接调用、回调与省略步骤，不把教学伪代码当作真实实现。
- 本课上游源码基线为 `v2.45.1`。本机 Git for Windows 的版本差异单独说明；只有使用匹配源码构建的二进制时，才把断点和局部变量作为该实现的运行证据。
- 实验仓库、远端模拟仓库、第三方 Git 源码与构建产物均放在根目录 `out/git-source/`；课程实验的 `init`、`reset`、`restore`、`commit`、引用写入等操作必须针对实验仓库。维护学习仓库本身的提交与推送仍按根规则和用户授权执行。
- 本课保留独立 Markdown 档案、菜单和日志，不复制其他主题的复习队列或调度状态。准备与冒烟检查只能记录为教练准备；完成章节仍须学习者操作、源码解释与当次验证证据。
