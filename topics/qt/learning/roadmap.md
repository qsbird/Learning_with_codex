# Qt 6 长期学习路线

## 目标与学习模式

目标是独立构建、测试和部署小型 Qt 6 Widgets 应用：能够解释对象生命周期、事件循环、模型/视图、绘制、异步任务和构建配置，并在需要时对一个**由学习者明确选择的**本地项目做只读对照。

默认使用两种可切换模式：

1. **独立学习（默认）**：只使用 `topics/qt/exercises/` 中的练习和 `out/qt/` 中的构建产物；不依赖任何外部项目、盘符或私有组件。
2. **项目对照（可选）**：学习者在 `learning/profile.md` 记录一个本地项目的名称、修订、Qt 版本和路径后，选取 1～3 个文件或符号作只读案例。路径缺失、项目无法构建或换到另一台机器时，立即退回独立学习；可改用 Qt 官方示例或另一个当次选定的项目。

每次开始前先填写 [profile.md](profile.md)。每次练习后把命令、结果、误解和下一步追加到 [log.md](log.md)。官方资料以 [Qt 6 CMake 入门](https://doc.qt.io/qt-6/cmake-get-started.html) 和 [Qt 6 移植指南](https://doc.qt.io/qt-6/portingguide.html) 为准。

## 每课的教学节奏

在给出任务、测试或代码阅读前，先核对本路线和学习记录：只要某个 Qt API、CMake 语法、模式或命令没有明确的学习证据，就把它当作新知识，而不是隐含前提。

1. **激活与预测**：从已学概念出发，提出一个可回答的行为预测。
2. **最小讲解**：说明它解决的问题，展示可运行的最小形式，逐项解释新语法、作用域和可观察效果。
3. **理解检查**：学习者用自己的话解释或预测一次；答案不足时先缩小示例再练习。
4. **有界练习**：只引入一个主要新点，给出文件、交付物和验收标准。
5. **验证与迁移**：运行构建、测试或观察行为；随后做一个小变体，或在可选项目中定位同类设计。
6. **记录**：只有能独立完成并解释关键决定时，才标记阶段完成。

每课建议 60～120 分钟。遇到环境问题时，先保留学习目标并使用最小可运行示例，不把工具链摩擦当作学习失败。

## P0 — 环境、Kit 与最小应用

**新知识门槛：** 先介绍 Kit、CMake 配置与构建目录的区别，再要求执行命令。

- 定位一套本机 Qt 6 Widgets Kit，记录 Qt 目录、编译器、生成器和 CMake 版本。
- 创建 `p0-hello-widget`：只包含 `QApplication`、一个 `QWidget` 和退出路径。
- 练习从空目录执行配置、构建和运行；构建目录固定在 `out/qt/p0-hello-widget/`。
- 可选项目对照：仅定位该项目的构建入口和程序入口；无法访问则跳过。

退出：能说明“配置时生成什么、构建时生成什么”，并附上成功命令与输出。

## P1 — CMake、Designer、资源与应用骨架

**新知识门槛：** 先讲 `find_package`、`target_link_libraries` 与 CMake 自动处理 `.ui/.qrc` 的最小写法；不要先把这些关键字塞进任务清单。

- 创建 `p1-widget-shell`：`QMainWindow`、菜单、工具栏、状态栏、一个 Designer 表单和一个 qrc 图标。
- 比较 Designer 生成的界面与代码创建控件各自适用的场景。
- 可选项目对照：找一个应用入口、一个 `.ui` 文件和其拥有者类；只说明关系，不整文件通读。

退出：资源可加载；能解释 `AUTOUIC`、`AUTORCC`、`AUTOMOC` 分别何时工作。

## P2 — QObject、对象树与信号槽

**新知识门槛：** 先以“按钮点击更新标签”的最小程序讲 `connect` 的四个角色和 context，再进入线程相关连接类型。

- 练习对象树的自动销毁、类型安全连接、lambda 的 context 和 `Q_PROPERTY` 的基本用途。
- 只有在已理解事件循环后，才介绍 Direct/Queued connection，并用线程 ID 或可见行为验证预测。
- 可选项目对照：选择一个自定义信号或连接点，标出 sender、receiver、生命周期与调用时机。

退出：能解释父子关系与 C++ 智能指针不是同一种所有权机制，并完成一次连接断开或对象销毁后的行为验证。

## P3 — Widgets、布局、Action 与主窗口交互

- 构建一个带表单、菜单动作和可启停计时任务的工具窗口。
- 先单独讲布局的最小规则，再练习嵌套布局、`QAction` 和状态同步。
- 可选项目对照：选一个小窗口或工具栏动作，追踪“用户操作 → 槽函数 → UI 状态”的一条路径。

退出：窗口缩放时布局正确；能解释控件状态为何不能只靠一次初始化。

## P4 — 模型/视图、事件与拖放

**新知识门槛：** 先用 `QStringListModel` 展示 model、view、index 与通知的关系；确认理解后才接触 `QAbstractItemModel`。

- 从现成模型开始，再实现一个只读二维模型；最后按需要扩展编辑、选择或拖放。
- 单独练习一个事件处理点（如键盘或鼠标），说明事件接收者和默认处理链。
- 可选项目对照：选一个模型类或事件过滤器，阅读不超过三个相关符号，并记录其模型通知或事件分发契约。

退出：能说明 `rowCount`、`data`、`index`、`parent` 的职责，以及错误通知为何会造成视图问题。

## P5 — 对话框、文件与配置

- 创建一个能打开、修改、原子保存 JSON 文件的小应用；用 `QSettings` 保存窗口状态和最近文件。
- 依次测试取消操作、无效路径、损坏文件和保存失败，保证原有内存状态不被破坏。
- 可选项目对照：选择一个设置或文件辅助类，区分用户设置、项目数据、资源和临时文件的路径策略。

退出：能解释 `QSaveFile` 的安全价值，以及模态与非模态窗口的生命周期差别。

## P6 — 数据、绘制与二维可视化

- 数据库只在真实需求出现时学习；没有需求时完成一个小型 SQLite 实验即可，并记录“为什么不引入数据库”。
- 创建 `p6-result-plot`：使用 `QGraphicsView` 或 `QPainter` 展示少量数据，支持缩放、空数据和窗口 resize。
- 可选项目对照：选择一个 scene/view/item 或自绘控件，画出坐标转换和所有权关系。

退出：能解释 `boundingRect()`、`paint()`、scene 与 item 的关系；针对空数据、单点和极端范围有验证。

## P7 — 自定义组件、库与可视化选型

- 将一个前序控件提取为 `QtWidgetsLabWidgets` target，并由独立 consumer 使用。
- 讲清 `PRIVATE`、`PUBLIC`、`INTERFACE` 的依赖传播后，再进行库拆分。
- Charts、三维可视化和插件按项目需求选学；先做 API 与依赖成本比较，不为了覆盖章节强行引入模块。
- 可选项目对照：选择一个组件 target 或渲染边界，记录复用边界而非照抄实现。

退出：库可独立构建；consumer 不复制 include 目录或 Qt 依赖。

## P8 — 多线程、取消、进程与通信边界

**新知识门槛：** 先用一个不会阻塞 GUI 的 worker-object 最小例子讲线程亲和性、事件循环和 queued connection；理解后才引入锁或复杂 IPC。

- 把一个耗时模拟任务移入 worker object，覆盖成功、取消、错误和窗口提前关闭四条路径。
- 实现最小 `QProcess` 日志查看器；网络、DBus 或 gRPC 仅由明确需求触发。
- 可选项目对照：选择一个后台任务或子进程封装，记录 GUI 回调与销毁顺序。

退出：能说明 worker 与 GUI 的线程边界，且有可重复的取消与关闭验证。

## P9 — 国际化、样式与部署

- 为练习应用加入中英文本、资源化样式和高 DPI 检查。
- 用 `cmake --install` 与平台部署工具生成运行目录，并在不依赖源码目录或 Qt PATH 的会话中启动。
- 多媒体和串口只在实际需求出现时升级为实践课。
- 可选项目对照：选择翻译、资源或发布配置的一处，说明其输入、产物和运行时查找路径。

退出：能定位翻译未生效或平台插件缺失的原因，并提供干净环境下的运行证据。

## P10 — Qt 5→Qt 6 方法与结业项目

独立学习模式创建 `topics/qt/exercises/qt-widgets-lab/`，汇总前序能力：主窗口、资源、模型/视图、设置、二维视图、可取消 worker、国际化、测试与安装规则。

可选项目对照模式才进行迁移审计，且始终只读：

1. 记录可运行基线、Qt 版本、编译器、第三方依赖和最小冒烟步骤。
2. 搜索弃用 API、旧式连接、构建宏、高 DPI 和平台插件假设；每项记录位置、Qt 6 变化、风险、验证和建议阶段。
3. 先在独立兼容性小例中验证替代 API，再提出可回退的小切口；不做全仓机械替换。

退出：结业项目完成 configure/build/test/install/run；能解释关键对象与线程的销毁路径。若做项目审计，输出的是分阶段建议而非未验证的代码改写。

## 复习、记录与暂缓项

- 每完成两个阶段，做一次混合复习：解释一个概念、预测一个行为、修改一个小条件。
- 每次只记录可复现的命令、输出、截图或可检查产物；阅读章节本身不能标为完成。
- Qt Quick/QML、深入 Qt SQL、Multimedia、SerialPort、复杂网络、三维渲染和全量迁移均默认暂缓，直到明确的产品需求或学习目标出现。
- 项目对照材料始终是可选学习辅助；不得提交、复制或依赖其文件。
